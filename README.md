# Farmacia Claridania

Sitio web estático elaborado con HTML5, CSS3 y JavaScript.

## Archivos
- `index.html`: estructura y contenido del sitio.
- `styles.css`: estilos y diseño adaptable a móviles.
- `script.js`: menú móvil y año automático del pie de página.
- `logo-farmacia.jpg`: logo proporcionado por Farmacia Claridania.

## Publicación en Vercel
1. Sube todos los archivos de esta carpeta a tu repositorio de GitHub.
2. Importa el repositorio desde Vercel.
3. Selecciona el preset **Other**.
4. Deja vacío el comando de compilación y coloca `.` como directorio de salida si Vercel lo solicita.
5. Pulsa **Deploy**.

La página usa rutas relativas, por lo que el logo debe permanecer en la misma carpeta que `index.html`.
